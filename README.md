# Aim Assist (Fabric, Minecraft 1.21.4)

Клиентский мод с меню настроек. Меню открывается клавишей **Right Shift**, **R** включает и выключает мод.

## Как получить готовый jar через GitHub (без установки Java и Gradle)

GitHub сам соберёт мод на своих серверах. Вам нужен только аккаунт на github.com.

1. Зайдите на https://github.com и нажмите **New repository** (зелёная кнопка).
   Назовите репозиторий, например `aimassist`, нажмите **Create repository**.
2. Загрузите файлы проекта:
   - на странице нового репозитория нажмите **uploading an existing file**;
   - распакуйте архив и перетащите в окно **всё содержимое папки `aimassist`**
     (`build.gradle`, `gradle.properties`, `settings.gradle`, папку `src`, папку `.github`, `README.md`);
   - внизу нажмите **Commit changes**.

   Важно: `build.gradle` должен лежать прямо в корне репозитория, а не внутри лишней папки.
   Папка `.github` скрытая. Если при перетаскивании она не загрузилась, создайте файл вручную:
   **Add file → Create new file**, в имени напишите `.github/workflows/build.yml` и вставьте содержимое из архива.
3. Откройте вкладку **Actions**. Сборка запускается сама после загрузки файлов.
   Если не запустилась, выберите **Build mod → Run workflow**.
4. Через 2-5 минут рядом со сборкой появится зелёная галочка.
   Откройте её и внизу страницы, в разделе **Artifacts**, скачайте `aimassist-jar`.
5. Распакуйте скачанный zip. Внутри два файла:
   - `aimassist-1.0.0.jar` - это сам мод;
   - `aimassist-1.0.0-sources.jar` - исходники, он не нужен для игры.

Красный крестик значит, что сборка упала. Откройте её, нажмите на шаг с ошибкой и скопируйте текст.

## Релиз со ссылкой на скачивание (необязательно)

Чтобы jar лежал во вкладке **Releases**:

1. На главной странице репозитория справа нажмите **Create a new release**.
2. В поле **Choose a tag** введите `v1.0.0` и нажмите **Create new tag**.
3. Нажмите **Publish release**.

Через несколько минут Actions соберёт мод и сам прикрепит jar к релизу.

## Как установить мод

Нужны Minecraft **1.21.4**, [Fabric Loader](https://fabricmc.net/use/installer/) и
[Fabric API](https://modrinth.com/mod/fabric-api) для 1.21.4.

1. Установите Fabric Loader для 1.21.4 и запустите игру один раз.
2. Положите `fabric-api-*.jar` и `aimassist-1.0.0.jar` в папку `mods`
   (Windows: `%APPDATA%\.minecraft\mods`).
3. В лаунчере выберите профиль `fabric-loader-1.21.4`.

## Сборка на своём компьютере

Нужны JDK 21 и [Gradle](https://gradle.org/install/) 8.11 или новее.

```
gradle build
```

Готовый jar будет в `build/libs/`.

## Настройки

Меню (Right Shift) состоит из двух разделов. Режимы выбираются из выпадающих списков, клик по заголовку карточки сворачивает её, а поиск ищет по всем разделам сразу.

- **Combat**
  - **Aim Assist** доводит камеру до центра цели и не перелетает его. Цель «залипает»: пока она жива и в зоне,
    аим не перескакивает на другого игрока. Настраиваются логика наведения, дальность, FOV,
    скорость по X и Y, плавность разгона и фильтры целей.
  - **Auto Attack** бьёт, когда прицел на хитбоксе игрока. Режим «Умный» сам определяет намерение: на земле или в спринте это комбо (бьёт сразу при полном заряде), а при зажатом прыжке или в воздухе это крит (ждёт падения). Для автоудара можно назначить клавишу или кнопку мыши (клик по строке «Клавиша», затем нажать нужную; Delete снимает клавишу, Esc отменяет). Режим «Переключатель» включает и выключает автоудар по нажатию, «Удержание» бьёт, только пока клавиша зажата. Если автоудар не бьёт, включите «Подсказки на экране»: над хотбаром появится причина. Настраиваются оружие в руке
    (любое, только меч, меч и топор), полный взмах, минимальный заряд, только криты и запрет удара при еде, щите или луке.
- **Visual**
  - **Target ESP** обводит игрока, на которого наведён аим. Стили выбираются из списка: статичная рамка, Pulse (расходящаяся волна), Волна (кольцо поднимается от ног к голове) и Молнии (мелкие разряды по телу). Настраиваются рамка, скорость эффекта, количество молний и цвет.
  - **Оформление** меняет цвет акцента и прозрачность окна.

Настройки сохраняются в `config/aimassist.json`.

Мод предназначен для своей игры, одиночных миров и серверов, где такие функции разрешены.
Перед игрой на чужом сервере проверьте его правила.
